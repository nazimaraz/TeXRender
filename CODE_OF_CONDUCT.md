# Code of Conduct

TeXRender is a small technical project. The goal is to keep discussion
clear, useful, and welcoming for people who want to learn from it, depend on it,
or improve it.

## Expected Behavior

- Be respectful of different experience levels and backgrounds.
- Keep criticism specific to code, design, documentation, tests, or project
  direction.
- Assume good intent when a question is incomplete, but ask for clarity when it
  matters.
- Share enough context that maintainers and contributors can reproduce a
  problem.
- Respect maintainer decisions about project scope and non-goals.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Dismissive comments about someone's identity, background, or skill level.
- Repeatedly derailing technical discussions after maintainers ask to refocus.
- Publishing private communication or security details without permission.
- Spam or low-effort promotional content.

## Enforcement

Maintainers may edit, hide, or delete comments; close issues or pull requests;
temporarily restrict participation; or block users who repeatedly violate these
expectations.

If you see a problem, report it through GitHub issue moderation tools or contact
the repository owner privately. Security-sensitive issues should follow
[SECURITY.md](SECURITY.md).
